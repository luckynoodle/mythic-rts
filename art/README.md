# Art

Drop 3D models here to replace the code-built placeholders. No code changes needed.

    art/<faction>/<unit or building id>.glb   e.g. art/humans/footman.glb
    art/resources/<gold|wood|stone>[_0..3].glb
    art/projectiles/<arrow|axe|bolt|boulder>.glb

See docs/ART_GUIDE.md for the conventions (metres, +Z forward, a "team" material, animation names).
